# かなキー

一个日语输入训练 Web 项目，包含五十音、单词记忆和语法辨析三个模式。五十音训练显示平假名或片假名，学习者键入对应罗马音；单词题提交后才在右侧展示答案、假名、罗马音和例句。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 题库与记录

内置词库在 `app/lessons.ts`，当前收录初级上册第 1–8 课的代表词汇。网站也支持下载 Word 模板并导入 `.docx` 题库；词汇、例句和语法辨析会按课次组织。同课次再次导入会替换该课的旧导入版本。

导入题库与最多 500 条答题记录保存在浏览器 `localStorage`，不会上传到服务器，也不会自动同步到其他设备。

## 训练模式

- 五十音训练：46 个基础清音，支持平假名、片假名和混合辨认；接受 `shi/si`、`chi/ti` 等常用写法
- 单词记忆：按课次练习日语写法、假名或罗马音输入
- 语法辨析：按课次集中阅读句型、用法说明和大字号例句

答案支持：

- 日语汉字或原词写法
- 平假名
- 片假名
- 罗马音（含部分常见输入变体）

## Word 模板字段

- 词汇表：课次、课名、中文释义、日语写法、平假名、罗马音、其他答案、日语例句、中文例句
- 语法辨析表：课次、课名、语法标题、句型/结构、辨析说明、日语例句、中文例句
